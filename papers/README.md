# Papers, Reading Notes, and Writing Pipeline

This folder organizes literature and writing outputs for teaching and research.

## Suggested Structure

- `reading-list/`: curated papers by topic
- `notes/`: critical summaries and discussion points
- `drafts/`: manuscript and report drafts
- `figures/`: reusable plots and visual assets

## Priority Themes

- Photonic materials for quantum technologies
- Hydrogen storage and production materials
- CO2 reduction materials and mechanisms
- Quantum algorithms and hybrid methods for material modeling

## Usage

Use this directory as the shared evidence base linking coursework, lab outputs, and publication-oriented writing.
