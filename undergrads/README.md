# Undergraduate Track: Quantum Photonic Material Modeling

This folder contains course content and project scaffolding for undergraduate students.

## Focus

- Foundations of quantum mechanics for materials
- Introductory photonic materials and devices
- Modeling pathways for hydrogen and CO2 applications
- Beginner-friendly quantum workflow exposure

## Recommended Contents

- Lecture notes and slides
- Guided labs and notebooks
- Small team project briefs
- Rubrics and assessment checklists

## Outcomes

By the end of this track, students should be able to explain core concepts, run supervised modeling workflows, and communicate results clearly in technical reports.
